# I Like Home Web

Landing y mini sistema web para I Like Home Gestion Inmobiliaria.

Incluye:

- Landing comercial para compra y venta inmobiliaria.
- Inventario de propiedades con hasta 6 fotografias por URL.
- PanelAdmin con propiedades, citas, CRM WhatsApp, tareas de equipo y politicas IA.
- Asesora virtual 24/7 en navegador.
- Conexion preparada para Supabase.

## Supabase

El archivo `I Like Home Landing/supabase-schema.sql` contiene las tablas necesarias para activar la sincronizacion real.

Proyecto configurado:

- URL: `https://gugcasbyewqvjqiiucnw.supabase.co`
- Key publica: configurada en `I Like Home Landing/script.js`
